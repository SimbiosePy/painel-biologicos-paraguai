# Painel – Biológicos no Paraguai

Painel interativo do mercado de insumos biológicos agrícolas no Paraguai: importações
(Aduana via Veritrade, ano-safra set–ago, set/2023–ago/2026), registros biológicos no
SENAVE e contexto do agro paraguaio.

Acesse: https://simbiosepy.github.io/painel-biologicos-paraguai/

O painel é um único arquivo (`index.html`) com dados e biblioteca de gráficos embutidos;
também funciona offline, aberto direto no navegador.
